# 设备工作区交互原型

这是已确认重整计划的第一阶段评审产物，**不属于生产网页、不连接 API，不证明后台功能已实现**。业务规则正文见[需求规格](../../docs/需求规格说明.md)，契约演进及页面设计见[详细设计](../../docs/详细设计.md)。

从仓库根目录运行：

```sh
eng/node eng/preview-workspace.mjs
```

Windows：`eng/node.ps1 eng/preview-workspace.mjs`。打开 `http://127.0.0.1:4178/`，端口可作为第二个命令行参数指定。只监听本机；`Ctrl+C` 停止。服务器只允许读取四个原型资源和首页，不公开仓库文件；CSP 禁止网络连接和表单网络提交。

- 数据均为虚构示例，IP 使用文档专用地址。原型操作只留在本页内存，刷新或“重置演示”恢复初始状态。
- 主导航只有“软件工作台”和“系统管理”。选工序看设备概况，选设备看全部软件，点软件看全部授权关联机台；软件视图会清除旧设备范围，支持返回原现场。
- “查找软件”提供 120 款虚构软件，每页 20 条，支持搜索和分类；它只选择软件，不再复制一套版本/状态管理页面。
- 软件表中直接勾选安装位置，选择版本后确认更新；没有第二次机台选择。多安装位置先展开、逐个选择，折叠时保留进行中任务提示。任务进度和更新记录跟随原设备/软件，切走再返回仍可见；任务不会改变现场版本。
- 版本与来源、工控机/PLC、IP、上报时间、接入和历史按需展开。“新增设备”自动编号；添加软件自动带入设备，可复用软件或 PLC 程序库，每台控制器的确认事实分开。
- GitLab 版本面板展示正式版本与折叠来源资料；演示导入新 Tag 不改变安装版本。显式查询会清除旧勾选，翻页保留选择并标明包含其他页，切换对象/人员清除旧选择。
- PLC 详情可上传**仅登记文件名的模拟归档**，填写现场验证与结论后演示转正式；不读取文件内容，不代表真实供包，不改变人工确认使用版本。
- 右上“预览身份”切换管理员、工程师、运维、只读范围；“人员与权限”展示拟实施矩阵。此开关仅用于原型，不引入生产测试开关。
- 本人密码放在账户菜单；请勿输入真实密码。原型不生成、存储或传输任何凭据。

评审重点是定位、名称、字段、操作顺序和权限范围。真实事务、迁移、后端权限、GitLab 配置写入、PLC 文件上传和厂家联调均属后续实现与验证，不能引用本原型作为通过证据。
